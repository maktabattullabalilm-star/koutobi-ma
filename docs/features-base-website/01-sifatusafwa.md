# Features & Functionalities — SifatuSafwa (sifatusafwa.com)

> Specialist online Islamic bookstore (Arabic books). Built on **PrestaShop**.
> Sells Arabic Islamic books worldwide, ships to 77+ countries, 100% online.
> Languages: English / French / Arabic. Currencies: EUR, GBP, USD.

## 1. International store & localization

- Multi-language store (EN / FR / AR) with a language switcher in the header.
- Multi-currency support (EUR / GBP / USD) via a currency dropdown.
- Country/region selector based on visitor location (shipping destination).
- "Worldwide delivery with UPS" promo + "Fast Processing Guaranteed" announcement carousel.
- Trustpilot reviews widget embedded on homepage + Trustpilot link in footer.
- Dedicated ``Shipping Information``, ``Returns & Refunds``, ``FAQ``, ``About Us``, ``Privacy Policy``, ``Terms of Sale``, ``Sitemap``, ``Contact Us`` pages.

## 2. Top navigation & mega menu

- Header quick actions: search box, account/login, wishlist (with counter), shopping cart (with counter).
- Main menu categories:
  - New Releases (New products, New editions, Gift card)
  - Authors (top authors + authors grouped **in chronological order by century** — 1st/2nd, 3rd, 4th century, etc.)
  - Arabic (language-learning section)
  - Quran & Tafsir / Aqeeda / Fiqh / Hadeeth / Reminders / History / Muslim Family / Student's Corner / Reading Corner / Stationery / Deals
- Breadcrumb navigation on inner pages.
- Mobile menu (burger) + responsive layout.

## 3. Homepage content blocks

- Hero slider / carousel with promo banners.
- "Recently Restocked" product carousel.
- Featured "Discover" editorial blocks (single-curated book highlights with rich descriptions).
- Themed "study curriculum" collections (e.g., Nahw from al-Ajurrumiyyah to al-Alfiyyah).
- "Explanations" collection hubs (Kitab at-Tawhid, Usul ath-Thalatha, al-Aqidah al-Wasitiyyah, al-Ajrumiyyah, Alfiah Ibn Malik, Umdah al-Ahkam, Bulugh al-Maram, 40 Hadiths of Nawawi — matn + explanations).
- Store credibility stats: **14 Years**, **550K books sold**, **77 Countries**, **4.8/5 rating**.
- Newsletter signup (email field + subscribe button).
- "For more information, contact us" CTA.

## 4. Category / listing pages

- SEO-optimized category header: title + descriptive paragraph (with "Show more / Show less").
- **Faceted filtering sidebar** ("Filter by"):
  - Category tree organized by topic AND by book-characteristics (e.g., "Mostly Vocalized 75–100% Harakat", "Lightly Vocalized", "Annotated and Interleaved Editions", "New editions", "Academic Research & Theses") — each with product count.
  - Author filter tree, with product counts per author.
- **Sorting options**: Relevance, Price (low→high / high→low), Name (A→Z / Z→A), New products first.
- Results counter ("1,522 results found").
- **Pagination** (1 2 3 … » »|) with "show all".
- **"Best Sellers in this Category"** block on top of listings.
- Product card contents:
  - Cover image, EN + Arabic title, single price
  - Badges: "New Release", "New edition", "Deals"
  - "Quick view" hover overlay
  - Wishlist / add-to-cart affordances
- Mobile: slide-out filter drawer.

## 5. Product detail page

- Image gallery with multiple thumbnails + zoom / lightbox ("Magic Scroll").
- Title in English + Arabic; author link (clickable → author/manufacturer page).
- Price display, "Tax included" label.
- **Editions selector (product variants)**: dropdown of different editions of the same book (Egyptian / Lebanese / Saudi…). Selecting an edition may change price, reference, description and specs.
- Quantity stepper (+ / −).
- "Add to cart" + wishlist button.
- Product reference code (SKU).
- Long-form editorial description (volume-by-volume table of contents, notes).
- **Data sheet / specifications** per edition: Title (Arabic), Author, Volumes, Format (cm), Cover type, Harakat level, Checking/preparation (tahqiq), Edition/publisher, Print quality.
- Cross-selling blocks:
  - "You might also like"
  - "Frequently purchased together" (bundle recommendations)
- Rating display ("Out of 5") on product and in reviews.

## 6. Search

- Global search box in header: "Search by Title, Author, Keyword…".
- Dedicated search-results page with filters and sorting.

## 7. Account / buyer experience

- Login, Registration, My Account, Wishlist, Purchase history (order history).
- Wishlist persists across sessions; quick add/remove.
- Cart drawer with summary + "View Cart"; full cart page.
- Checkout flow with login-gated options.

## 8. Marketing & trust features

- Announcement carousel for promos/shipping deals.
- Gift card product category.
- Deals / Clearance & Bargain category.
- Newsletter capture (footer + section) with consent language.
- Cookie consent banner with granular category controls (GDPR): Necessary, Statistics, Marketing — cookie list with purpose/expiry.
- Social links (Facebook, Twitter/X, Instagram) + Trustpilot.
- Support widget (floating "Support" button) + live-chat-style contact form.

## 9. Footer

- Newsletter block + contact email/address (Cork, Ireland).
- Customer Support column: Contact us, Shipping information, Returns & refunds, FAQ.
- Information column: About Us, Privacy policy, Terms of Sale, Sitemap.
- My Account column: Login, Registration, My account, Wishlist, Purchase history.
- Tagline: "The first Muslim bookstore specialized in Arabic books, 100% online".

## 10. Technical notes (as observed)

- Platform: PrestaShop 8 (theme with Magic Scroll, cookiesplus GDPR module, mega-menu, facet filters).
- Cloudflare protection in front of the site.
- Fast, image-heavy product cards served via CDN.
